No hay modelos certificados. La generación de HTML no prueba Bluetooth, ESC/POS, corte automático, impresión directa ni apertura de gaveta. Imprimir desde celular depende del sistema y de su servicio de impresión compatible; no se presupone que cualquier impresora Bluetooth funcione.

## Cuando se consiga un equipo

1. Registrar marca/modelo, ancho real del papel, conexión, sistema operativo, navegador y versión del controlador.
2. Desde una venta de prueba guardada, elegir 58 u 80 mm en el POS o historial. Permitir la ventana del sitio. En el diálogo seleccionar la impresora y papel correctos, escala 100%, sin encabezados/pies del navegador. Ajustar márgenes según el controlador y comprobar el resultado real.
3. Revisar nombres largos, folio, fecha, prestador y cobrador, cantidades, importes y total. Para efectivo, comprobar recibido y cambio. No debe cortarse texto ni importes.
4. Reimprimir el mismo folio: debe seguir existiendo una sola venta. Probar cancelar impresión y volver a solicitarla. Revisar también el comprobante de caja.
5. Guardar fotografía/video del papel y resultado. Marcar únicamente el modelo/conexión comprobados como compatibles; repetir para el otro ancho. Un PDF tampoco sustituye el papel.

## Si se cae la red al cobrar o cerrar

1. Si no se inició el cobro, detener nuevos cobros en el sistema hasta recuperar conexión.
2. Si aparece una operación por confirmar, **no crear otra venta ni volver a cobrar al cliente**. Conservar la pestaña, el perfil del navegador y su almacenamiento. No borrar datos ni cambiar de cuenta mientras se recupera.
3. Restablecer internet; datos móviles/hotspot son una contingencia que debe comprobarse en el dispositivo real. No se garantiza que el navegador detecte una API inaccesible solo por el indicador de conexión.
4. Usar **Recuperar resultado** o **Reintentar y recuperar ticket**. El sistema consulta/reintenta la misma operación. Revisar su folio, total y estado antes de continuar.
5. Si sigue fallando, conservar evidencia sin contraseñas y solicitar soporte para conciliar. No asumir que un error de red significa que la venta no se guardó.

No existe venta offline certificada ni cola de cobros sin conexión. El pago registrado como tarjeta en el POS no prueba un cargo del banco.

## Si solo falla imprimir

La venta permanece guardada. Restablecer conexión o permitir ventanas y volver al historial para reimprimir el mismo folio. Si la impresora falla, corregir controlador/papel/conexión y repetir la impresión; no repetir el cobro. El ticket de venta no es CFDI.
